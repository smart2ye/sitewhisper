# SiteWhisper — فاحص أمني سلبي للمواقع

أداة خفيفة لفحص المواقع بطريقة **سلبية**، تُصدر تقارير بالعربية عن:
- رؤوس الأمان (Security Headers)
- مصادقة البريد (SPF / DMARC)
- شهادة TLS

**الحالة:** قيد التطوير المبكر. سطر أوامر فقط، بلا واجهة ويب بعد.

---

## ما تفحصه

| الفحص | ما يقرأه | لماذا يهم |
|---|---|---|
| **رؤوس الأمان** | CSP، HSTS، X-Frame-Options، X-Content-Type-Options، Referrer-Policy، Permissions-Policy، COOP، CORP | أكثر ما يُهمَل في المواقع العربية، وهو خط الدفاع الأول ضد XSS وclickjacking |
| **مصادقة البريد** | سجلات SPF وDMARC العامة | غياب DMARC يعني أن أي شخص يستطيع انتحال بريد نطاقك |
| **شهادة TLS** | المُصدر، تاريخ الانتهاء، SAN، صلاحية السلسلة | شهادة منتهية = الموقع لا يفتح عند الزائر |

كل ما تقرأه الأداة هو ما يعلنه الخادم للعامة أصلًا.

---

## ما لا تفعله (مهم)

SiteWhisper **لا** تقوم بـ:
- إرسال payloads لاختبار XSS أو SQLi
- تخمين مسارات أو ملفات (`/.env`, `/.git/`, `/backup.sql`)
- فحص منافذ (port scanning)
- محاولة دخول بكلمات مرور افتراضية
- استغلال أي ثغرة بأي شكل

هذه كلها أفعال هجومية، لا سلبية. الأداة لا تنفذها.

## التثبيت

    pip install -r requirements.txt

المتطلبات: Python 3.11+، `requests`، `dnspython`.

---

## الاستخدام

    python -m sitewhisper example.com

المخرجات:
- تقرير في الطرفية (مُلوّن).
- ملف HTML قابل للتنزيل.

مثال مختصر:



فحص: example.com
─────────────────────────────

🛡️  رؤوس الأمان ............ 6/8
✅ HSTS              max-age=31536000
✅ CSP               default-src 'self'
❌ Referrer-Policy   (مفقود) — يوصى بـ: strict-origin-when-cross-origin

📧  البريد ................. 1/2
✅ SPF               v=spf1 include:_spf.example.com ~all
❌ DMARC             (مفقود) — يوصى بـ: v=DMARC1; p=quarantine

🔒  TLS ................... ✅
المُصدر: Let's Encrypt R3
ينتهي: 2027-01-15 (78 يومًا)

─────────────────────────────
النتيجة: 12/20 (جيد)

## المعمارية



sitewhisper/
├── sitewhisper/
│   ├── main.py        # نقطة الدخول (CLI)
│   ├── checks/
│   │   ├── headers.py     # رؤوس الأمان
│   │   ├── email_auth.py  # SPF/DMARC
│   │   └── tls.py         # شهادة TLS
│   ├── report.py          # توليد التقارير
│   └── templates/
│       └── report.html
├── tests/
├── requirements.txt
└── LICENSE



قرارات متعمدة:
- **بلا Flask** في V1 — CLI فقط.
- **بلا قاعدة بيانات** — لا حاجة.
- **بلا LLM** — كل الفحوصات قواعد ثابتة، لا يحتاج استدلال.
- **بلا OAuth** — لا حسابات، لا مستخدمين.

## خارطة الطريق

**V1 (الحالي):**
- رؤوس الأمان
- SPF + DMARC
- شهادة TLS
- تقرير HTML

**V2 (لاحقًا):**
- DKIM
- أعلام الكوكيز
- security.txt / robots.txt
- تقرير Markdown

**V3 (اختياري):**
- واجهة ويب بسيطة (Flask)

**لن نضيف أبدًا:**
- فحص هجومي
- تخمين ملفات
- كلمات مرور افتراضية
- استغلال ثغرات
