# 🕵️ SiteWhisper Pro v2 - أداة فحص أمني متقدمة

أداة فحص أمني احترافية متكاملة لفحص المواقع والخوادم واكتشاف الثغرات الأمنية بواجهة سيبرانية عصرية.

## ✨ الميزات الرئيسية

### 1. فحص رؤوس الأمان (Security Headers)
- فحص شامل لجميع رؤوس HTTP الأمنية
- توصيات تفصيلية لكل رأس ناقص
- تقييم مستوى الحماية الكلي

### 2. فحص الثغرات الأمنية
- **XSS (Cross-Site Scripting)**: كشف نقاط الحقن المحتملة
- **SQL Injection**: اكتشاف ثغرات قاعدة البيانات
- **Open Redirect**: كشف عمليات إعادة التوجيه غير الآمنة
- **كشف المنافذ المفتوحة**: فحص المنافذ الشائعة

### 3. فحص MikroTik المتخصص
- كشف هوية أجهزة MikroTik RouterOS
- فحص منفذ Winbox (8291)
- كشف ثغرة CVE-2025-6563
- اختبار كلمات المرور الافتراضية

### 4. خريطة الموقع (Site Mapper)
- استخراج تلقائي للروابط من sitemaps
- اكتشاف جميع الصفحات والموارد
- تحليل هيكل الموقع

### 5. إدارة التقارير
- تقارير HTML تفصيلية قابلة للتنزيل
- سجل كامل للفحوصات السابقة
- إحصائيات شاملة للثغرات المكتشفة
- نسخ النتائج بنقرة واحدة

## 🚀 البدء السريع

### 1. تسجيل الدخول
انقر على "ابدأ الآن" وقم بتسجيل الدخول عبر Manus OAuth

### 2. بدء فحص جديد
- أدخل عنوان الموقع أو IP في حقل "عنوان الموقع أو IP"
- اختر نوع الفحص المطلوب:
  - **فحص رؤوس الأمان**: فحص رؤوس HTTP فقط
  - **فحص الثغرات**: فحص الثغرات الشائعة
  - **فحص MikroTik**: فحص متخصص لأجهزة MikroTik
  - **خريطة الموقع**: استخراج الروابط والصفحات
  - **فحص شامل**: جميع الفحوصات معاً
- انقر على "بدء الفحص"

### 3. عرض النتائج
- شاهد التقدم الفعلي للفحص
- بعد الانتهاء، ستظهر النتائج في سجل الفحوصات
- اعرض الإحصائيات والثغرات المكتشفة

### 4. تنزيل التقرير
- انقر على زر التنزيل (أزرق سماوي) لتنزيل تقرير HTML
- انقر على زر النسخ (أصفر) لنسخ النتائج إلى الحافظة
- انقر على زر الحذف (وردي) لحذف التقرير

## 📊 مستويات الخطورة

| المستوى | اللون | الوصف |
|--------|-------|-------|
| **حرجة** | أحمر | ثغرات تهدد الأمان بشكل مباشر |
| **عالية** | برتقالي | ثغرات خطيرة تتطلب معالجة فورية |
| **متوسطة** | أصفر | ثغرات يجب معالجتها |
| **منخفضة** | أخضر | تحسينات أمنية موصى بها |

## 🎨 واجهة المستخدم

### التصميم السيبراني
- خلفية سوداء عميقة (#0a0a0a)
- ألوان نيون وردية (#ff0055) وسيان كهربائي (#00ffff)
- تأثيرات توهج خارجي قوية
- عناصر HUD مينيمالي

### المكونات الرئيسية
- **لوحة الفحص**: إدخال البيانات واختيار نوع الفحص
- **شريط التقدم**: عرض حالة الفحص الفعلية
- **سجل الفحوصات**: عرض جميع الفحوصات السابقة
- **إحصائيات الثغرات**: عداد الثغرات حسب المستوى

## 💡 نصائح الاستخدام

### للحصول على أفضل النتائج:
1. استخدم الفحص الشامل للحصول على تقييم كامل
2. قم بفحص متعدد الأهداف لمراقبة عدة مواقع
3. احفظ التقارير المهمة للمراجعة لاحقاً
4. قارن النتائج بين الفحوصات المختلفة

### الفحص الدوري:
- قم بفحص موقعك أسبوعياً على الأقل
- راقب التحديثات الأمنية الجديدة
- تابع التوصيات المقدمة في التقارير

## 🔒 الأمان والخصوصية

- جميع البيانات مشفرة أثناء النقل
- التقارير محفوظة بشكل آمن في قاعدة البيانات
- لا يتم مشاركة البيانات مع أطراف ثالثة
- الوصول محدود للمستخدم المسجل فقط

## 📱 التوافقية

- متوافق مع جميع المتصفحات الحديثة
- واجهة مستجيبة للأجهزة المختلفة
